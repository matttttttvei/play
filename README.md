# PLAYSPACE

Небольшой игровой хаб: четыре обложки, каждая из которых ведёт на отдельный проект. Чтобы перейти к игре, нажми на её фото.

## Как открыть

Открой `index.html` в браузере. Установка зависимостей не нужна. Папка `assets` и файл `styles.css` должны находиться рядом с `index.html`.
